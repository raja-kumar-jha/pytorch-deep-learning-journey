### Key Takeaways

Some important things I learned from this notebook:

1. Tensors are the fundamental data structure used by PyTorch.
2. Tensor shape is extremely important when performing operations.
3. Matrix multiplication requires compatible tensor dimensions.
4. `reshape()`, `view()`, `squeeze()`, `unsqueeze()` and `permute()` are useful for changing tensor dimensions.
5. PyTorch tensors can work with NumPy arrays.
6. Random seeds can make experiments reproducible.
7. GPUs can accelerate tensor computations.
